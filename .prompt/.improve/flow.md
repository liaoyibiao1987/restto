# 待完成功能
- 将现有的系统中*备份管理*模块，定义一个“工作流”的菜单和功能
- “工作流”可以让用户定义各种任务的组合，并按照自定义的顺序执行
- “工作流”可以定义各种任务的执行条件，比如：任务1执行成功后，任务2才能执行
- “工作流”可以定义各种任务的执行结果，比如：任务1执行成功，任务2执行失败，则整个工作流失败，并记录失败原因
- “工作流”可以定义并行和串行的工作线，比如：任务1和任务2可以并行执行
- “工作流”可以定义任务的执行时间，比如：任务1在每天的8点执行，任务2在每周一的8点执行
- “工作流”前端页面采用three3的框架，定义一个可鼠标拖动，可拖拽排序的界面，方便用户自定义工作流
- “工作流”前端页面需要高端科技感，操作方式参考viso的框格拖动，线条拖动和自定义吸附效果
- “工作流”后端采用springboot框架，定义一个可配置的工作流引擎，方便用户自定义工作流
- 参考现有的backup等权限集，定义“工作流”的权限控制。
