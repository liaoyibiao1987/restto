# 一、角色定位
你是一名资深后端/全栈架构开发工程师，精通企业级后台 RBAC 权限管理系统设计与开发，熟悉主流权限体系设计规范、数据权限控制、接口权限拦截、菜单动态渲染逻辑。输出代码遵循企业级开发规范，结构分层清晰、安全性高、可扩展性强、适配后续功能迭代。

# 二、核心开发需求
基于现有系统角色体系进行全面优化重构，搭建完整的企业级 RBAC 角色权限管理功能，包含五大核心模块，具体功能要求如下：

## 1. 用户管理模块
1. 实现系统用户新增、编辑、删除、批量删除、启用/禁用、重置密码功能
2. 用户列表分页查询、条件筛选（账号、姓名、状态、创建时间）
3. 支持用户绑定多角色、解除角色绑定
4. 账号唯一性校验、密码规则校验、用户信息数据脱敏
5. 记录用户创建、修改、状态变更操作轨迹

## 2. 角色管理模块
1. 角色新增、编辑、删除、批量操作、角色启用/禁用
2. 角色列表分页查询、条件筛选
3. 核心功能：角色关联菜单权限、关联接口权限、数据权限配置
4. 角色唯一性校验，禁止重复角色标识
5. 支持超级管理员角色隔离保护，禁止随意删除、禁用

## 3. 权限管理模块
1. 实现接口权限、功能权限、按钮权限精细化管控
2. 权限标识统一规范定义，支持权限编码全局唯一
3. 权限新增、编辑、删除、树形结构展示
4. 支持权限分配、权限复用、权限批量授权
5. 实现接口拦截校验，无权限用户禁止访问对应接口

## 4. 菜单管理模块
1. 系统菜单树形结构搭建，支持一级菜单、子菜单、按钮级菜单
2. 菜单新增、编辑、删除、排序、显示/隐藏配置
3. 菜单绑定对应权限标识、路由地址、组件路径、图标、排序权重
4. 根据用户角色动态渲染侧边栏菜单，实现不同角色不同菜单权限
5. 菜单数据缓存优化，提升系统加载效率

## 5. 日志管理模块
1. 操作日志：记录所有用户新增、编辑、删除、授权、状态变更等操作，记录操作人、IP、操作时间、操作内容、请求参数、操作结果
2. 登录日志：记录用户登录、退出、登录失败记录，包含账号、IP、设备、登录时间、登录状态
3. 日志分页查询、条件筛选、日志详情查看
4. 支持日志定时清理、日志数据持久化，禁止手动篡改日志数据

# 四、功能约束与业务规则
1. 超级管理员拥有系统全部权限，不受权限拦截限制，数据权限全覆盖
2. 普通角色仅拥有分配的菜单、按钮、接口权限
3. 已绑定用户的角色禁止直接删除，需先解除绑定
4. 核心权限、基础菜单禁止随意删除，增加系统保护机制
5. 所有修改、删除、授权操作需留存操作日志，可追溯
